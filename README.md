# GrowAI

Premium AI-powered Instagram growth SaaS starter.

## Stack
- Next.js + TypeScript
- Tailwind CSS
- Framer Motion
- Recharts
- Three.js
- Supabase-ready service boundaries

## Local setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000.

## Vercel

1. Push this repository to GitHub.
2. Import the GitHub repository into Vercel.
3. Add environment variables from `.env.example`.
4. Deploy.

The Instagram, AI, analytics and billing integrations are intentionally represented by local providers in this starter. Replace them with real providers after configuring the required accounts and permissions.

## Important

This product is designed for legitimate audience growth. It does not create or sell fake followers, fake likes, fake comments, bot accounts, or artificial engagement.
